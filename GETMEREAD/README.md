## 写作风格说明

- **大白话**：每条尽量用通俗的比喻和「因为…所以…」讲清楚动机。
- **文字 + 图**：先讲过程，再在关键处放 Mermaid 图。
- **更新规矩**：新增功能或项目更新后，在对应模块文件里**追加**一节并刷新文字与图，别新建同名文件。
