# Graw

Веб-панель управления сервером с интерфейсом в стиле операционной системы. Фронтенд построен на Vue 3 + Vite, бэкенд — на FastAPI. Предоставляет мониторинг системы в реальном времени, управление Docker, управление процессами, файлами, веб-терминал и заметки.

## Как установить?

docker run -d -p 8041:8000 --name graw-panel shunx/graw:latest

Замените `8041` на свой порт. Graw использует единую обёртку в Docker: достаточно одного порта, настраивать несколько записей не нужно.

## Возможности

- **Система учётных записей и прав** — вход по JWT, роли (администратор / обычный пользователь), управление аккаунтами, принудительная смена пароля. Все защищённые API требуют заголовок `Authorization: Bearer <token>` после входа
- **Интерфейс в стиле рабочего стола** — оконные приложения, панель задач, ярлыки на рабочем столе, перетаскивание, разворачивание/сворачивание
- **Мониторинг в реальном времени** — CPU, память, диск, сеть, нагрузка; данные и графики транслируются через WebSocket
- **Управление веб-сайтами** — создание/удаление/изменение виртуальных хостов Nginx / Apache, запуск и остановка, генерация и просмотр конфигурации
- **Управление базами данных** — подключения MySQL / MariaDB / Redis, просмотр БД/таблиц, выполнение команд SQL / Redis
- **Планировщик задач** — управление Cron-выражениями (обёртка над Linux crontab / Windows schtasks)
- **Брандмауэр** — правила портов и чёрные/белые списки IP (iptables / netsh)
- **SSL-сертификаты** — загрузка собственных сертификатов и запрос Let's Encrypt (certbot)
- **Центр логов** — просмотр и очистка системных, веб-сайтовых и панельных журналов
- **Управление Docker** — просмотр контейнеров и образов, запуск, остановка, логи и прочее
- **Управление процессами** — просмотр списка и подробностей запущенных процессов
- **Управление файлами** — обзор каталогов, загрузка/скачивание, изменение прав, сжатие/распаковка, копирование и переименование
- **Веб-терминал** — терминал в браузере на базе xterm.js для прямого управления сервером (WebSocket аутентифицируется через `?token=`)
- **Заметки** — быстрое сохранение и просмотр системных заметок

## Быстрый старт

### Требования

- Python 3.8+
- Node.js 16+
- (Необязательно) Docker-движок — для функции управления Docker

### Ручной запуск

**1. Запуск бэкенда**

```bash
cd backend
python -m venv .venv
source .venv/bin/activate  
# Windows: .venv\Scripts\activate
pip install -r requirements.txt # при первом запуске
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
# Или, если вы разрабатываете:
py start.py

```

**2. Запуск фронтенда**

```bash
cd frontend
pnpm install
pnpm run dev
```

### Продакшн-сборка

Продакшн-сборка фронтенда выводится в `frontend/dist`; бэкенд автоматически обнаруживает и подключает этот каталог как статические ресурсы:

```bash
cd frontend
npm run build
```

После этого просто запустите бэкенд, и полное приложение будет доступно по адресу `http://localhost:8000`.

## Обзор API

| Модуль | Префикс | Описание |
|------|------|------|
| Auth | `/api/auth` | вход, текущий пользователь, смена пароля, управление пользователями (администратор) |
| System | `/api/system` | CPU, память, диск, сеть, нагрузка, поток WebSocket в реальном времени |
| Sites | `/api/sites` | управление виртуальными хостами (Nginx/Apache) |
| Databases | `/api/databases` | управление подключениями и запросами MySQL/MariaDB/Redis |
| Cron | `/api/cron` | планировщик (Linux crontab / Windows schtasks) |
| Firewall | `/api/firewall` | правила брандмауэра по портам и IP |
| SSL | `/api/ssl` | загрузка собственных сертификатов и запрос Let's Encrypt |
| Logs | `/api/logs` | просмотр и очистка логов |
| Docker | `/api/docker` | управление контейнерами и образами |
| Process | `/api/process` | список процессов и подробности |
| Files | `/api/files` | просмотр файлов, передача, права, сжатие/распаковка |
| Terminal | `/api/terminal` | сессии WebSocket-терминала (аутентификация через `?token=`) |
| Notes | `/api/notes` | CRUD заметок |

За исключением `/api/auth/login` и `/api/health`, все эндпоинты требуют заголовок `Authorization: Bearer <token>`.

## Учётная запись по умолчанию

При первом запуске автоматически создаётся запись в `backend/data/users.json`:

- Логин: `admin`
- Пароль: `admin123`
- Статус: принудительная смена пароля после первого входа

Ключ подписи хранится в `backend/data/secret.key` (генерируется автоматически при первом запуске). В продакшене храните этот файл и `users.json` надёжно и смените пароль по умолчанию.

Подробные определения API смотрите в файлах маршрутов в `backend/app/routers/`.

## Сброс пароля

Если вы забыли пароль администратора или не можете войти в веб-панель, сбросить пароль можно прямо на сервере с помощью CLI-скрипта (запускать бэкенд не требуется):

```bash
cd backend

# Список всех аккаунтов
python reset_password.py --list

# Сброс указанного аккаунта (интерактивный ввод нового пароля)
python reset_password.py admin

# Без указания аккаунта скрипт предложит выбрать
python reset_password.py
```

Скрипт напрямую читает/записывает `backend/data/users.json`, скрывает ввод пароля и после сброса автоматически снимает флаг «сменить пароль при первом входе». Длина нового пароля — не менее 6 символов.

## Конфигурация

Настройки прокси dev-сервера фронтенда находятся в `frontend/vite.config.js`; по умолчанию они перенаправляют `/api` и WebSocket на `http://localhost:8000`:

```js
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8000',
      changeOrigin: true,
      ws: true
    }
  }
}
```
